## 💬 一句话推荐语

> 低频的压迫像海水灌满胸腔，玻璃琴在水底幽幽回响——那是面对无底深渊时，连呼救都发不出的绝望。

## 🎧 听感描述

极低频的 Abyssal Drone 把人一寸寸压进深海，玻璃琴（Glass Armonica）在水底留下诡异而神圣的回声，水琴（Hydraulophone）的流动水声告诉你——这里没有底。

三种声音叠加出"下坠 → 窒息 → 湮没"的曲线：不是哭出来的伤感，而是身体被环境碾碎的过程。适合主角坠入深渊、世界观崩塌、面对不可名状的恐怖或无法战胜的宿命。
