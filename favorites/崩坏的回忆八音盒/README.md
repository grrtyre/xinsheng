## 💬 一句话推荐语

> 反向钢琴把旋律倒吸回去，像回忆被强行抽离——你眼睁睁看着那座八音盒走调、断裂，却救不回任何一段美好。

## 🎧 听感描述

反向钢琴（Reversed Piano）把音符倒放，像回忆被强行抽离、时间倒流却回不去；新古典暗潮（Neoclassical Darkwave）把原本优雅的旋律压暗、侵蚀，如八音盒在锈蚀中走调。

整首从一段还算完整的旋律，逐渐坍塌成碎片、失真与漫长混响——对应"心理防线崩溃"与"记忆扭曲"。你听得见它坏掉的过程，正如看得见自己守住的东西如何被销毁。适合视觉小说黑化线、残酷真相揭晓、失去最重要之人的独白。
