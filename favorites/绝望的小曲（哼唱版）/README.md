## 🎧 听感描述

这首歌的核心是**无力感**——一种被生活压垮、说不出话、只能哼出声的绝望。

- **前段**：缓慢、低沉的哼唱，像独自坐在黑暗里发出的声音
- **中段**：哼唱逐渐加重，情绪开始积压
- **高潮**：人声突然爆发——不是嘶吼，而是把所有压抑的绝望一次性倾泻出来
- **尾段**：回归低吟，像爆发后的虚脱，余韵悠长

整首歌依靠**人声的力度变化**完成"无力 → 爆发 → 虚脱"的情绪曲线，格外刺痛。
