## 🎧 听感描述

八音盒是"美好回忆"的意象，而这首曲子让它在你耳边**一点点坏掉**——不是突然碎裂，而是你看着它走调、断裂，却救不回任何一段旋律。

- **反向钢琴（Reversed Piano）**：把钢琴录音倒放，音符不是"落下"而是"倒吸回去"，像回忆被强行抽离、时间倒流却回不到过去，自带诡异的不安与失重感。
- **Neoclassical Darkwave（新古典暗潮）**：新古典的优雅织体被暗潮的低频压暗、侵蚀，像一座八音盒在锈蚀中渐渐走调，温润里渗出寒意。
- **整体曲线**：从一段还算完整的旋律，逐渐坍塌成碎片、失真与漫长的混响拖尾——对应"心理防线崩溃"与"记忆扭曲"。你听得见它坏掉的过程，正如看得见自己守住的东西如何被销毁。

## 🎬 适用场景

- 视觉小说："黑化"路线（堕落线 / Yandere）、残酷真相揭晓的瞬间
- 影视 / 动画：主角失去最重要之人时的内心独白
- 游戏：角色黑化、记忆回溯崩坏、Bad Ending 过场
- 短视频 / 广播剧：虐心剪辑、回忆杀破碎、精神崩塌转场
