## 🎧 听感描述

这不是一首"哭出来"的伤感曲，而是一首**压下来**的曲子——它模拟的是身体被环境碾碎的过程，而非内心的悲伤独白。

- **Abyssal Drone（深渊低频嗡鸣）**：极低频的持续音墙，像万吨海水一寸寸压上耳膜与胸腔，制造无法挣脱的**物理压迫**与**窒息感**，是整首曲子的脊柱。
- **玻璃琴（Glass Armonica）**：空灵、幽冷的高频泛音，像沉没神殿里残存的祈祷回声，诡异而神圣，把"压迫"染上一层**不可名状的恐怖**色彩。
- **水琴（Hydraulophone）**：由水流触发的水声旋律，湿冷、流动、没有尽头，暗示脚下是**无底深渊**——你听见水，却看不见底。

三者叠加，完成一条"下坠 → 窒息 → 湮没"的曲线：低频把你按进深海，玻璃琴在水底幽幽回响，水琴的流动告诉你——这里没有底，你只会一直沉下去。

## 🎬 适用场景

- 影视 / 动画：角色坠入深渊、世界观崩塌、沉没与溺没的瞬间
- 克苏鲁 / 恐怖：面对**不可名状的恐怖**、无法理解之物时的氛围铺陈
- 游戏：深海关卡、失落遗迹探索、Boss 战前"无法战胜的宿命"过场
- 短视频 / 广播剧：末日、精神崩塌、绝望独白的转场配乐
