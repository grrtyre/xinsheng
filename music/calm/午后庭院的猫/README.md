## 🎧 听感描述

灵感是一只猫趴在午后窗台、阳光穿过树叶洒下来的瞬间——整首曲子要的是"有机而灵动"的微光感，而不是工整的背景垫乐。

- **Kalimba（拇指琴）× Celesta（钢片琴）**：两种"叮叮"音色交织，清亮、圆润、像猫爪轻轻踩过琴键，是整首曲子灵动气质的来源。
- **Pizzicato Strings（拨弦）**：做旋律骨架，一粒一粒的拨奏带来"有机"的颗粒感，比长弓更轻、更活。
- **Brushed Snare（刷鼓）**：以刷子轻扫代替重击，只给一点质感与呼吸，绝不压人。
- **[pause] 停顿标记**：段落间刻意留出停顿，制造"猫突然停下、再跳走"的断句效果——这是它的灵魂，让音乐有真实的呼吸与俏皮。

整体气质：温暖、轻盈、有微光，像午后庭院里一缕会动的光。

## 🎬 适用场景

- 视觉小说 / 动画：慵懒午后、庭院与窗台、猫咪与日常、治愈系过场
- 游戏：村庄 / 家园 / 安全区的温柔 BGM，刻意避开俗套"游戏感"
- 生活类短视频 / Vlog：撸猫、阳台、手作、慢生活记录
- 冥想 / 放松：需要"有机微光"而非纯白噪音的背景
- 商业空间：独立书店、花店、猫咖的轻盈背景音
