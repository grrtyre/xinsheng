## 🎧 听感描述

这是一首"待在家里、阳光正好"的曲子——它不抢戏，却让画面更可信。

- **木吉他分解和弦**：温润、循环的拨弦织体，提供**松弛的日常烟火感**，像傍晚厨房飘来的饭香，是整首曲子的生活底色。
- **钢琴 + 弦乐组合**：钢琴勾勒干净的主旋律线条，弦乐以轻薄的垫音托住情绪，二者叠加出"**生活温度**"——不煽情，却让人安心。
- **合成器空气感音色**：薄而透的高频铺底，制造一层**新鲜的听觉质感**，让这件"家常"的编制不落俗套、不易撞款。
- **轻电子鼓点（克制）**：律动灵动但量感很轻，只负责推一点呼吸感，绝不来沉重。**明快但不喧闹**，完全不会盖过人声。

整体气质：放松、明亮、有质感，适合长时间循环而不疲劳。

## 🔁 循环友好型结构

采用「短引入 → 主旋律段 → 轻量过渡 → 主旋律再现 → 短收尾」的设计：

- **中段天然支持无缝循环播放**：主旋律段与再现段之间靠轻量过渡衔接，过渡段刻意制造听觉"呼吸差"，让循环接点不明显。
- **长时间背景音友好**：结构留白充足、配器克制，作为 Vlog / 直播 / 店内背景音循环数遍也不易产生疲劳感。

## 🎬 适用场景

- 游戏：村庄 / 小镇 / 营地等安全区的日常 BGM
