## 📖 项目简介

**心声（Xinsheng）** 是一个开放的纯音乐素材仓库，致力于为视频创作者、播客制作人、独立开发者、学生及其他任何需要背景音乐的人提供一个**免费、可商用、易于获取**的音乐资源库。

所有音乐素材均采用 [**CC BY 4.0**](https://creativecommons.org/licenses/by/4.0/) 协议发布——你可以自由使用、修改和分发，只需署名原作者即可。

---

## ✨ 特点

- 🆓 **完全免费** —— 所有素材均可免费下载与使用
- 🎯 **可商用** —— 在署名前提下可用于商业项目
- 🎼 **纯音乐** —— 无歌词干扰，适合作为背景音乐
- 📂 **分类清晰** —— 按风格/场景分类，便于检索
- 🔄 **持续更新** —— 定期补充新的音乐素材

## 📂 目录结构

```
xinsheng/
├── README.md                  # 项目说明（本文件）
├── LICENSE                    # CC BY 4.0 协议
├── .gitignore
└── music/                     # 音乐素材根目录
    ├── ambient/               # 氛围 / 环境音乐
    ├── piano/                 # 钢琴 / 轻音乐
    ├── cinematic/             # 影视 / 史诗配乐
    ├── electronic/            # 电子 / 节奏
    ├── acoustic/              # 原声 / 民谣
    ├── lofi/                  # Lo-Fi / 休闲
    └── _catalog.md            # 音乐素材总目录（含下载链接）
```

> 💡 若某分类目录尚未创建，说明暂未收录该类型音乐。欢迎通过 PR 投稿补充。

## 🎧 使用方式

### 1. 直接下载

进入对应的音乐分类目录，点击文件名，在右上角选择 `Download` 即可下载单个文件。

### 2. 克隆整个仓库

```bash
git clone https://github.com/grrtyre/xinsheng.git
```

### 3. 查阅总目录

所有已收录的曲目及其详细信息（风格、时长、适用场景）汇总在 [`music/_catalog.md`](./music/_catalog.md) 中。

## 🤝 参与贡献

欢迎提交 Pull Request 补充优质的纯音乐素材。投稿前请注意：

1. 确保你拥有该音乐的版权或其已处于公共领域
2. 投稿音乐须为**纯音乐**（无人声歌词）
3. 推荐格式：`.mp3`（兼容性最佳）或 `.wav`（无损）
4. 单文件建议不超过 **15MB**
5. 请同步更新 `music/_catalog.md` 目录
